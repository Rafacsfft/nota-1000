# Contributing

Contributions that improve clarity, accessibility or the revision experience are welcome.

1. Open an issue describing the student problem you want to solve.
2. Create a focused branch.
3. Keep claims about ENEM evaluation accurate and sourced.
4. Run `npm run lint` and `npm test`.
5. Open a pull request explaining the learner impact and validation performed.

Never commit real student essays or personal information. Use fictional or explicitly authorized examples only.
